# Development

```sh
uv sync
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

The frontend is plain HTML, CSS and ES modules in `src/cc_calendar/static/`, with no build step.
Tests use synthetic logs only; never commit real transcripts.

## Screenshots

The screenshots are rendered from fictional data generated by `scripts/demo_data.py`. They use
your installed Google Chrome:

```sh
uv run --with playwright python scripts/screenshots.py
```

## This site

This site is built with [Zensical](https://zensical.org/) from `docs/` and `zensical.toml`.
GitHub Actions deploys it to GitHub Pages on every push to `main`.

Preview it locally:

```sh
uv run --group docs zensical serve
```
